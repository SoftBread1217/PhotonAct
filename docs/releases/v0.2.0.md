# PhotonAct v0.2.0

PhotonAct v0.2.0 connects documented external curve tables to reproducible PyTorch experiments.
The release adds a generic local preparation command and opt-in hardware effects. Existing
`CurveActivation` and `HysteresisActivation` calls retain their v0.1.1 behavior.

## Highlights

- `photonact prepare` converts CSV or XLSX tables with explicit long-form or separate up/down
  column mappings. It can explicitly compute output power from input power and transmittance.
- Preparation preserves the source and writes canonical CSV, provenance metadata, and an audit
  report containing the source SHA-256 and conversion options. Existing output files are not
  overwritten.
- `photonact inspect` reports branch coverage and missing provenance warnings.
- `HardwareAwareActivation` adds opt-in input drift, output-side insertion loss, output range
  limits, quantization, and seeded Gaussian readout noise.
- The bundled synthetic example compares each effect independently and in combination.

## Upgrade and first run

Install from the repository:

```bash
python -m pip install -e ".[data]"
python examples/hardware_effects.py
photonact prepare examples/curves/sample_phh.csv --output-dir local_data/roundtrip \
  --name roundtrip --input-column input_power --output-column output_power \
  --branch-column branch --input-unit normalized_power --output-unit normalized_power \
  --source-description "Bundled synthetic demonstration" --data-kind synthetic \
  --license CC0-1.0 --lower-threshold 0.6 --upper-threshold 1.4
photonact inspect local_data/roundtrip/roundtrip.csv
```

`openpyxl` is an optional dependency for XLSX input only. The core remains a PyTorch package with
no spreadsheet dependency.

## Scientific boundary

The supplied example and effect parameters are synthetic demonstrations, not calibrated device
models. The input/output units, effect order, random generator, and gradient approximations must be
chosen and reported by the user. The release does not ship the motivating paper's source workbook,
derived curve, or local HTML and does not claim to reproduce its accuracy.

## Validation

The release gate covers Python 3.10-3.12, Ruff, Mypy, citation validation, curve and effect tests,
the synthetic example, CSV/XLSX preparation, and an installed-wheel smoke test. A private local
curve can be used as an additional smoke test without adding it to the repository.
