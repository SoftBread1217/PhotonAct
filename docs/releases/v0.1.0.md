# PhotonAct v0.1.0

PhotonAct v0.1.0 adds an explicit-state PyTorch model for two-branch optical hysteresis while
preserving the simple stateless curve adapter introduced in v0.0.1.

## Highlights

- `HysteresisActivation` implements deterministic lower/upper threshold switching without hidden
  mutable trajectory state.
- Single-step, time-major sequence, batched-state, autograd, device transfer, and serialization
  behavior are documented and tested.
- Curve metadata now records data kind, response quantity, wavelength, polarization, and optional
  hysteresis thresholds.
- A deterministic converter can prepare a legitimately held Figure 4(b) source workbook locally,
  recording provenance and computing output power from power transmittance.
- The bundled `sample_phh` curve remains synthetic, openly licensed demonstration data.

## Scientific and data boundary

This release does not include the paper's original or derived research data and does not claim to
reproduce the paper's neural-network accuracy. The local converter writes to Git-ignored
`local_data/` by default. Publishing derived data requires separate author or rights-holder approval
and an explicit data license.

## Validation

- Python 3.10, 3.11, and 3.12 are covered by GitHub Actions.
- Ruff linting, Mypy type checking, 20 automated tests, both examples, wheel construction, and an
  installed-wheel smoke test form the release gate.

## Upgrade

No v0.0.1 API is removed. Existing `CurveActivation` code continues to work. Hysteresis users add
`lower_threshold` and `upper_threshold` metadata and call `HysteresisActivation` with explicit
initial state.

See [CHANGELOG.md](../../CHANGELOG.md) and [hysteresis.md](../hysteresis.md) for the complete change
list and state-transition semantics.
