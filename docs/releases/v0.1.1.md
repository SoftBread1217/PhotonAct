# PhotonAct v0.1.1

PhotonAct v0.1.1 makes a documented hysteresis curve understandable before it is placed inside a
model. The new local explorer turns any valid two-branch curve into a self-contained browser page
without uploading the curve or adding a web framework dependency.

## Highlights

- `photonact demo sample_phh` opens an interactive up/down-scan explorer in the default browser.
- A slider, automatic full-cycle scan, threshold markers, current branch, and explicit high/low
  state make the hysteresis semantics visible.
- Curves containing a `transmittance` column can switch between output power and power
  transmittance.
- The generated page includes provenance, physical units, wavelength, polarization, and data
  license from the curve metadata.
- The GitHub project page now leads with a synthetic-data preview and a 60-second quick start.

## Privacy and scientific boundary

The generated HTML embeds every plotted point. It remains local by default and must be shared only
when the source curve's license permits it. This release contains no original or derived data from
the motivating paper. The bundled `sample_phh` preview is hand-authored synthetic data under CC0.

## Validation

- Python 3.10, 3.11, and 3.12 are covered by GitHub Actions.
- Ruff, Mypy, citation validation, 25 automated tests, both Python examples, curve inspection, and
  local-demo generation form the source-checkout release gate.
- The wheel is installed into an isolated environment and must inspect the bundled curve and
  generate the interactive demo before the release is accepted.

## Upgrade

No v0.1.0 API is removed. Existing `CurveActivation` and `HysteresisActivation` code continues to
work. The explorer is an additive CLI command and introduces no new runtime dependency.
